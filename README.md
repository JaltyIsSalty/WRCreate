# WRCreate

WRCreate is a desktop theorycrafting tool for War Robots. It is currently in **alpha**, so features and data may change and you may encounter bugs.

## Current features

- Browse and select from 12 robots, from Stryx through Nekton.
- Choose pilot skills, specializations, and passive modules.
- View base stats and calculated passive build bonuses.
- Create, save, load, and delete named builds stored locally as JSON.

Weapons and drones are not implemented yet. Conditional combat bonuses are shown separately from passive totals.

## Getting started

Run `WRCreate v0.1.0-alpha.exe` from its package folder. For Windows (10/11) only!
